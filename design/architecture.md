# HiddenMateの構成

## 基本方針

覆面駒をfmrsの新しい駒種として実装しない。覆面駒の正体を具体化した通常局面を複数作り、それぞれの合法手・王手・詰みを`fmrs_core`で判定する。

```text
VariableProblem
  │  候補駒種の直積と初形合法性
  ▼
HiddenState
  ├─ ConcreteWorld (V1=飛, V2=銀)
  ├─ ConcreteWorld (V1=龍, V2=銀)
  └─ ConcreteWorld (V1=龍, V2=金)
         │
         └─ fmrs_core::PositionAux
```

## 観測着手

具体世界では駒種が確定しているが、棋譜から覆面駒の種類は直接見えない。各世界の具体着手を`ObservedMove`へ射影し、同じ観測着手を一つにまとめる。

攻方ではfmrsが生成する王手だけが残るため、王手義務自体が候補世界を絞る。受方では王手を外せる世界だけが残る。

## 詰み

最終局面で、残るすべての具体世界に合法応手がない場合だけ詰みとする。一つでも応手可能な世界があれば、詰みは証明されていない。

## 拡張予定

現在の`HiddenState`は具体世界を明示列挙する。覆面駒が少ない短編では検証しやすい。透明駒では位置も未知になって組合せが増えるため、同じ公開インターフェースの背後にSAT/SMTまたはBDD方式を追加する。
